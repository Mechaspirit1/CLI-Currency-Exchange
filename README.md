# CLI-Currency-Exchange
A command line tool for quick currency exchange and exchange rate visualization

# Installation
* Clone this repository
* run ```chmod +x curex.py```
* and copy or move the script to a $PATH direcotry (```mv curex /usr/local/bin```) or (```cp curex /usr/local/bin```)

# Functionality
Includes two modes
* Mode 1 prints currency list and exchange rates based off a currency chosen by the user
* Mode 2 converts a value from one currency to the other

# Tools used
Vanilla Python
